# godot-csharp-experiments

A lab of small, focused **C#** experiments in **Godot 4.6.2 (.NET build)** — the
C# sibling of [`water-kit`](../water-kit) (GDScript). Each technique is isolated
in one self-contained, self-validating scene. This repo is where the work that
genuinely benefits from C# lives: large stateful systems, zero-GC `struct` data,
compiler-checked interfaces/generics, and tight numeric loops.

## Prerequisites

| Tool | This project uses | Notes |
|---|---|---|
| **Godot** | `/Applications/Godot-mono.app` (4.6.2 **.NET**) | The **standard** Godot build can't run C#. Use the mono/.NET app. |
| **.NET SDK** | 8.0.x at `~/.dotnet` | On `PATH` via `~/.zshrc`. Verify: `~/.dotnet/dotnet --version`. |
| **Editor** | VS Code + C# Dev Kit | Godot has no built-in C# editor. |

## Open / build / run

```bash
# Open the project in the .NET editor
/Applications/Godot-mono.app/Contents/MacOS/Godot --path .

# Or build from the CLI first
~/.dotnet/dotnet build
```

The default run scene is `scenes/03_mna_wave.tscn`. Any scene can be launched
directly (`Godot-mono … res://scenes/NN_<name>.tscn`) or rendered to a PNG via the
screenshot harness (`tools/shoot.tscn` — see `CLAUDE.md`).

## Relationship to water-kit

`water-kit` stays GDScript (fast iteration, no build step — right for tiny
one-file demos). This repo takes on the techniques where C#'s structs, interfaces,
static typing, and speed pay off. Shaders (`.gdshader`) are portable between the
two verbatim.
